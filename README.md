# LearnPath – Mentor–Student Learning & Progress Tracking Platform

LearnPath is a web-based platform designed to connect mentors and students in a structured learning environment. It enables mentors to manage learning activities, share resources, assign tasks, conduct assessments, and monitor student progress. Students can access their learning materials, complete assignments and tests, track their progress, and communicate with mentors through the platform.

The platform provides separate dashboards and role-based functionality for mentors and students, making the learning process more organized and accessible.

**Deployed Application:** https://learnpath-livid.vercel.app/

## Key Features

### Mentor Features
- Dashboard to monitor student learning activities and progress.
- Manage students and their learning activities.
- Create and manage assignments.
- Create and manage tests and assessments.
- Upload and share learning resources.
- Review student submissions and assessment performance.
- Manage assignment extension requests.
- Receive notifications and manage updates.

### Student Features
- Personalized dashboard to track learning progress.
- View and access assigned tasks.
- Submit completed assignments.
- Attempt available tests.
- Access learning resources shared by mentors.
- Receive notifications and updates.
- Request extensions for assignments when needed.

## Technology Stack

Frontend: React, TypeScript
Styling: Tailwind CSS
Backend Services: Supabase
Authentication: Supabase Authentication
Database: PostgreSQL
Deployment: Vercel

## Application Workflow

1. Users access the platform through the login page.
2. After authentication, users are directed to the appropriate dashboard based on their role.
3. Mentors manage students, create assignments and assessments, and share learning resources.
4. Students access their assigned learning activities, submit assignments, and attempt assessments.
5. Mentors review student work and monitor learning progress.
6. Notifications help users stay informed about relevant updates.
