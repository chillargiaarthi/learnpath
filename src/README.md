# LearnPath

### Connecting Guides with Students

LearnPath is a web-based platform that connects Guides and Students in a
structured learning environment. It provides a centralized space for
managing tasks, assessments, learning resources, submissions, and student
progress.

## Features

- Guide–Student connection
- Task creation, assignment, and submission
- Task drafts and deadline extension requests
- Online tests with automatic evaluation
- Test review and retake management
- Learning resource sharing and assignment
- Student activity tracking
- Light, Dark, and Reading modes

## User Roles

### Guide
Create and assign tasks, conduct tests, share resources, review submissions,
and manage student activities.

### Student
Access assigned tasks and resources, complete activities, take tests, submit
work, and request extensions or retakes.

## Technology Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Supabase
- PostgreSQL
